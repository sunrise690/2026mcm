# 前轮发布判定记录：严格 V3

本文件记录上一轮的速度门槛与当时暂不推送的决定。用户随后允许用
极小风险换取较大收益，并允许动态路线；后续 risk_v4 有独立的风险、
收益和新场景确认门禁。本目录作为其冻结依赖与对照保留，后续发布
判定见 risk_v4/evidence/release_gate.json。

本版当时完成了连续覆盖几何实现和离线验证，但没有达到此前交接约定的
绝对速度门槛。因此当时只保存本地实验分支，没有自动推送 GitHub，也未更新
q3/current。

新确认集中，冻结快速版只有 129/140 全清，其 239.8032 s/源仅是成功
子集的均值；它与严格证书版本承担的完成约束不同。这个差异说明新算法
具有可靠性价值，但不能把“同类证书版本内更快”替代此前的绝对速度
推送门槛。

configs/evaluation_protocol.json 保留实验前设置的比较协议；它说明
严格证书版本之间如何比较，不构成用户对放宽原推送条件的授权。
若要按独立可靠性版本发布，应先取得用户对这项速度与可靠性取舍的确认。
