# iter_086_deferred_half_bootstrap

继承 iter_084。低于高密度触发阈值时保留全部四个800米覆盖点，但只立即扫描前两个；另外两个覆盖点与当前已定位清除目标、后验探点统一进入滚动最近邻和2-opt路线。每完成一个测量或清除动作后重新选下一步，发现达到16个时自动取消尚未执行的覆盖移动。

该版本不减少覆盖点，只改变访问时机和顺序；高密度分支继续采用前期少量找点、主体动态路线和后期风险找补。策略只读取公开响应与自身belief。

30例筛查结果：总平均362.82秒/源，10源462.93秒/源，16源302.86秒/源，全清14/30；相对iter_084新增失败7例、救回1例。动态排序明显缩短移动，但早期清除尝试达到上限后未随新测量重开，导致可靠性下降；本版作为高速实验保留。
