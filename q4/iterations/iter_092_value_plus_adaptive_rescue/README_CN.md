# iter_092_value_plus_adaptive_rescue

继承 iter_090。先执行覆盖率至少0.34的单步价值救援；若该救援未触发，且当前仅发现12–13个源、剩余活动源风险至少0.40，则最多执行3次重新计算后验的连续1600米外圈找补。
