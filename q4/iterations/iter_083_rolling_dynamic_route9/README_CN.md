# iter_083_rolling_dynamic_route9

继承 iter_082。中心完整扫描至少发现9个频道时进入滚动动态路线：每次测量或清除后，用最新公开 belief 重新生成一个探点，与当前可清目标共同执行最近邻和2-opt排序，只走排序后的第一步，然后再次规划。动态探点最多4个，并过滤重复测点与低覆盖高绕行点。中心发现少于9时完整保留 iter_078 的固定覆盖路线，以撤销13--14源边界上的新增漏检。

策略只使用公开响应、公开生成规则和自身 belief，不读取真实源数、真实位置或隐藏真值。

边界回归结果：4个定向案例中，撤销了中心发现8个时的两项新增失败，但中心发现10个的15源案例仍新增失败，且未保留iter_082对16源案例26091388的救援。因此本版作为滚动重规划实验保留，不替代稳健基线。
