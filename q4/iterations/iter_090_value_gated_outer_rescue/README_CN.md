# iter_090_value_gated_outer_rescue

继承 iter_089。二次1600米外圈救援除剩余活动源风险门槛外，还要求预测覆盖率至少0.34；低价值外圈只计算、不移动。

30例诊断中唯一被 iter_088/089 救回的案例预测覆盖率为0.36，本门槛用于保留该救回并消除大部分无效移动。

## 离线结果

固定30例：总平均388.069 s/源，10源490.323，16源302.072，全清21/30。

独立随机35例：总平均376.545 s/源，10源472.263，16源299.712，全清29/35；相对 iter_084 无新增失败，但该随机集没有触发额外救回。
