# iter_084_dynamic_early_late_rescue9

继承 iter_082，采用“前期找点、主体动态路线、后期找补”的混合策略。中心完整扫描至少发现9个频道时跳过固定四点环；前期仅规划少量粒子覆盖探点，并与已定位清除目标统一执行最近邻和2-opt路线。高密度主体路线中，发现数不超过14时继续在清除终点扫描未知频道，充分利用已经发生的移动；主体结束后，若高密度分支仍只发现14个及以下，即使普通风险门限偏低，也强制执行一次后验定向找补；发现15个时保留原风险门限，避免把真实15源场景拖慢。

中心发现少于9时完整保留 iter_078 的固定覆盖路线。策略只使用公开响应、公开生成规则和自身 belief，不读取真实源数、真实位置或隐藏真值。

140例冻结留出集结果：总平均399.35秒/源，10源507.26秒/源，16源293.63秒/源，全清101/140；相对iter_078无新增失败，救回1例。该版本将中心高发现阈值提高到9，并保留高密度清除终点的完整未知频道机会扫描。
