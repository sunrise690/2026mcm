# 第六支路：原地机会扫描与短前缀实验

本支路只使用现有离线模拟器及冻结的旧35开发案例，没有运行新留出，也没有访问远端。所有策略只消费公开接口响应；实际源数和坐标仅由结束后的评测器统计。

先对旧35+旧70日志核查发现，iter003相对iter001增加的1421.64秒/局中，1407.18秒来自未发现频道搜索，比例98.98%。因此没有直接改保守清除走廊，而测试清源终点原地机会搜索。

| 候选 | 35例全清 | 平均秒/已清源 | 源清除率 |
|---|---:|---:|---:|
| p010 | 33/35 | 541.38 | 99.56% |
| p005 | 35/35 | 542.35 | 100.00% |
| triangle800_tail2 | 19/35 | 408.12 | 94.07% |
| square1000_tail2 | 25/35 | 426.51 | 96.48% |
| triangle800_cross_tail2 | 19/35 | 405.18 | 94.95% |
| triangle800_cross_tail1 | 17/35 | 373.21 | 93.19% |

| ratio_far800 | 26/35 | 406.37 | 97.80% |
| ratio_homing | 25/35 | 450.78 | 97.36% |

主 `workspace` 冻结 p005：保留iter003完整14点发现路线，清源结束点距离已普查点至少300米且当前位置后验可见率至少0.05时扫描未知频道，尾部后验补查4次收为2次。旧开发35/35全清，542.35秒/源，优于原iter003同批592.95秒/源，但没有达到350目标。

短三角800分支使用中心加三个800米环点作为固定前缀，随后清源级联。cross分支在清源位置还测量仅有一条示向且距离已有观测至少300米的频道，尽量免费取得第二示向。最激进的noout版本达到348.81秒/源，但只有17/35全清、总源清除率92.09%，不可据此宣称完整求解已达到350；这里只作为速度与覆盖损失的实测证据。

方形1000、交会探针前进400改800、单示向步进homing均未得到可合并的提速效果。保守定位改动不建议合并。

每次评测的代码哈希、逐动作公开响应、评测器trace及全部失败案例均保存在reports下。每个子候选保持独立源代码；p010早期版本位于snapshots/p010_workspace。所有结果均为反复调参后的开发表现，不能称为独立验证。
