# iter_093_adaptive_rescue_max14

继承 iter_092，仅将连续动态外圈找补的发现数上限从 13 提高到 14，使首次找补发现第 14 个源后仍可继续重算后验并寻找剩余源。

状态：实验候选；需通过失败种子筛选、固定30例和独立随机35例后再判断。

## 离线结果

困难6例筛查：全清由1/6提高到2/6，救回种子6259529，无新增失败。

固定30例：总平均390.373 s/源，10源490.323，16源302.072，全清21/30。

独立随机35例：总平均385.952 s/源，10源472.263，16源299.712，全清31/35，无新增失败。相对 iter_092 多救回1例，但总平均增加4.345 s/源，只保留为高全清率实验候选。
