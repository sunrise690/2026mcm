# iter_074_fast_deferred_outer_rescue

状态：**实验候选，不替换 `q4/CURRENT.json` 的稳定版。**

## 核心思路

在 `iter_073_deferred_fifth_joint_route` 的“延后第 5 个探测点并与清除路径联合规划”思路上继续压缩时间：

1. 启动探测改为中心点 + 3 个 120° 等分环点；
2. 启动半径使用 525 m；
3. 第 5 个探测点延后，并从候选外圈点中按“未知源后验可见概率 - 路程代价”选择；
4. 对已经在较近位置扫过的未知频道设置 450 m 重扫门限，减少重复测量；
5. 保留一次后验救援；当发现源数量较少时，再触发第二个 1500 m 外圈定向救援点；
6. 所有已发现源仍通过联合路线清除，不允许用真值信息选点。

## 结论

该版本已显著跨过 350 s/source 目标，但可靠率仍低于当前稳定版，因此这里只作为实验迭代保存，不更新 `CURRENT.json`。
