# iter_088_outer1600_second_rescue

继承稳健版 iter_084。第一次后验尾探仍未发现全部源时，增加一次1600米定向外圈找补；候选使用12扇区均衡覆盖评分和0.00012路程惩罚，参数来自GitHub实验候选的外圈救援思路。

目标是优先救回高定向、外圈漏发现案例，提高全清率。所有动作只使用公开反馈，并由本地离线模拟器复测。

- 总平均：407.154 s/源
- 10源：524.442 s/源
- 16源：309.470 s/源
- 全清：21/30

比 iter_084 多全清1例，但总平均增加23.784 s/源，固定执行外圈找补成本过高。
