# iter_087_evidence_reopens_clear

继承 iter_086，修复动态路线中的清除资格锁死：频道在获得新的 direction 或 no_signal 公开证据后，重新获得两次清除资格；每个频道仍设置四次总清除上限，防止低质量证据触发无限重试。

目标是用新增证据真正更新定位和清除决策，提高全清率，同时保持动态路线节省的移动时间。测试结果待本地冻结30例离线筛查写入。

## 离线筛查结果（固定30例）

- 总平均：362.825 s/源
- 10源：462.933 s/源
- 16源：302.862 s/源
- 全清：14/30

结果与 iter_086 完全一致，重新开放清除资格没有产生可测增益，保留为无效消融版本。
